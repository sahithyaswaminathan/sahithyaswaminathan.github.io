2019 · NUS EE5902 Multiprocessor Systems

Heuristic Task Scheduling for Multiprocessor Systems

Four Python scheduling algorithms — Ant Colony Optimization (ACO), a Genetic Algorithm + ACO hybrid (GAACO), a Modified List Scheduling Heuristic (MLSH), and a GA + MLSH hybrid (GAMLSH) — that assign precedence-constrained DAG tasks, generated with TGFF, across a configurable number of processors, with the DAG file and processor count set at runtime. Compared on makespan, schedule length, processor utilization, and fitness, the GAMLSH hybrid came out best overall. Co-authored with Mrinalini Shridhar — foundational work on the scheduling and utilization trade-offs behind today's cluster and core schedulers.
